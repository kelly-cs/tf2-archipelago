# Glossaire

Le glossaire de référence est le fichier `CONTEXT.md` du dépôt, en anglais. Il
définit les mots que partagent Archipelago et Mann vs Machine, et quel sens
s'applique où.

La version courte, en français, est
[Les mots d'Archipelago, pour les joueurs MvM](archipelago-for-mvm-players.md).

| Mot | Sens dans ce livre |
| --- | --- |
| Bridge | Le programme qui relie le serveur de jeu à la room. Le lanceur le fait tourner pour vous. |
| Check | Un endroit atteint dans le jeu : une vague réussie, une mission réussie, un premier tank, un premier géant. |
| Déblocage | Un objet que la partie a reçu et que le serveur applique : une classe, un emplacement d'arme, un ticket de mission. |
| Emplacement d'arme | Primaire, secondaire ou mêlée. Le « slot » de Mann vs Machine. |
| Lanceur | `tf2ap.exe` ou `tf2ap-linux-amd64`. Il installe et fait tourner le serveur. |
| Multiworld | La session partagée par tous les joueurs d'une room. |
| Objet | Quelque chose que la partie reçoit du multiworld. |
| Palier | La difficulté d'une mission : normal, intermediate, advanced, expert, haunted. |
| Partie | Une seed jouée par ce serveur, du premier check à l'objectif. |
| Plugin | Le code SourceMod dans le serveur de jeu. Il voit les vagues et applique les déblocages. |
| Réserve | Les missions parmi lesquelles la seed pioche, ou les objets que la seed distribue. |
| Room | Une seed hébergée, avec une adresse. |
| Seed | Le fichier qui décrit un multiworld. |
| Slot | Votre serveur entier, vu par Archipelago. |
| Ticket de mission | L'objet qui met une mission dans la partie. |
