# Glossaire

Le glossaire vit dans [`CONTEXT.md`](../../CONTEXT.md), à la racine du dépôt.

Il est là plutôt qu'ici parce qu'il est le premier fichier qu'un agent lit, et
que les instructions de `CLAUDE.md` nomment ce chemin. Une copie dans le livre
devient une deuxième version, et les deux divergent ensuite.

Ce fichier est en anglais, comme les termes qu'il fixe. Le jeu les écrit en
anglais dans le chat et le code les emploie tels quels. Les logs les portent
sous cette même forme. Un terme traduit ici ne se lit donc nulle part ailleurs.

Il définit les termes employés dans `gamedata/`, `bridge/`, `apworld/` et
`plugin/`. Archipelago et Mann vs Machine partagent plusieurs mots et leur
donnent des sens différents ; ce fichier tranche lequel s'applique où.
