# Les mots d'Archipelago, pour les joueurs MvM

Archipelago est un randomizer multi-jeux. Plusieurs joueurs, chacun dans son
propre jeu, partagent une seule réserve d'objets. Quand vous atteignez un
endroit dans votre jeu, vous trouvez un objet. Souvent, il appartient à
quelqu'un d'autre. Quand cette personne atteint un endroit dans son jeu, elle
trouve un des vôtres.

Le [glossaire](https://archipelago.gg/glossary) et la
[FAQ](https://archipelago.gg/faq) d'Archipelago expliquent les termes
généraux. Cette page explique ce qu'ils veulent dire ici.

## Les mots

| Mot | Dans Archipelago | Ici, dans Mann vs Machine |
| --- | --- | --- |
| **Multiworld** | Une session partagée par tous les joueurs | La room que votre serveur rejoint |
| **Slot** | Le jeu d'un joueur dans le multiworld | Votre serveur entier. Un seul slot, quel que soit le nombre de joueurs. |
| **Seed** | Le fichier qui décrit un multiworld | Ce que l'application Archipelago génère à partir de vos options |
| **Room** | Une seed hébergée, avec une adresse | Ce que `archipelago.gg` crée quand vous y envoyez la seed |
| **Check** | Un endroit que vous atteignez dans votre jeu | Une vague réussie, une mission réussie, le premier tank ou le premier géant d'une mission |
| **Objet** | Quelque chose que vous recevez | Une classe, un emplacement d'arme, un ticket de mission, un bonus d'arme, un paquet de crédits, un piège |
| **Objectif** | Ce qui termine votre part du multiworld | La mission la plus dure de la partie, ou une part des missions |
| **Indice** | Demander où se trouve un objet | Tapé dans le chat du jeu avec `!ap hint` |

Deux mots entrent en collision avec le vocabulaire du jeu :

- **Slot.** Le slot d'Archipelago est votre serveur. Le slot de Mann vs
  Machine est un emplacement d'arme : primaire, secondaire, mêlée. Quand ce
  livre dit « emplacement d'arme », il parle de l'arme.
- **Objet.** L'objet d'Archipelago est quelque chose que la partie vous donne
  pour de bon. L'objet de Mann vs Machine est un ramassage qui disparaît à la
  fin de la vague. Ce livre dit « objet » au sens d'Archipelago.

## Deux règles qui surprennent les joueurs d'Archipelago

- **Le serveur partage chaque déblocage.** Une classe que la partie trouve
  s'ouvre pour tout le monde sur le serveur, au même moment. Il n'y a pas de
  déblocage par joueur.
- **Un check appartient à l'équipe.** L'équipe réussit la vague ensemble, et
  c'est ça le check. Peu importe qui était sur le serveur.

## Deux règles qui surprennent les joueurs MvM

- **Vous commencez presque sans rien.** Une à quatre classes et un à trois
  emplacements d'arme, selon la difficulté de la partie. Vous trouvez le
  reste.
- **Un emplacement d'arme verrouillé est vide.** Le serveur retire l'arme à
  chaque apparition et à chaque réapprovisionnement, jusqu'à ce que la partie
  trouve cet emplacement.
