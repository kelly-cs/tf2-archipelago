# Archipelago pour les joueurs de MvM

Le [glossaire](https://archipelago.gg/glossary) et la
[FAQ](https://archipelago.gg/faq) d'Archipelago expliquent multimonde, slot,
graine, objet, check et filler. Tout cela s'applique ici sans changement, donc
cette page ne le répète pas.

Ce qui suit est la partie qui nous appartient : les mots qu'Archipelago et Mann
vs Machine emploient tous les deux, avec des sens différents.

| Mot | Chez Archipelago | Dans Mann vs Machine |
| --- | --- | --- |
| Check | Un emplacement que vous envoyez en l'atteignant | Rien. Le jeu n'a pas cette notion. |
| Objet | Ce qu'un autre monde vous envoie | Ce que vous ramassez dans une vague, et perdez à la fin |
| Slot | La partie d'un joueur dans le multimonde | Un emplacement d'arme : principale, secondaire, corps à corps |
| Mission | Pas un terme | Une suite ordonnée de vagues, sur une carte |

Un « déblocage de slot » est donc un **objet** Archipelago qui ouvre un
**emplacement d'arme** de Mann vs Machine. Les deux sens du mot tiennent dans
cette seule phrase. [`CONTEXT.md`](../../CONTEXT.md) tranche toutes les autres
collisions.

Deux règles de ce monde surprennent qui connaît déjà Archipelago :

- **Le serveur partage chaque déblocage.** Un emplacement s'ouvre pour tout le
  monde, pas pour le joueur qui a envoyé le check. Un seul slot Archipelago
  couvre le serveur, et non un par joueur.
- **Un check appartient à l'équipe, pas à vous.** Votre équipe réussit la vague
  ensemble, et quiconque est sur le serveur au moment où elle tombe a fait le
  check.

[Ce que le randomiseur change](./what-the-randomizer-changes.md) dit ce que cela
fait à une partie de MvM.
