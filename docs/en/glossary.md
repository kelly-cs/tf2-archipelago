# Glossary

The glossary lives in [`CONTEXT.md`](../../CONTEXT.md), at the root of the
repository.

It sits there rather than here because it is the first file an agent reads, and
the instructions in `CLAUDE.md` name that path. A copy in the book becomes a
second version, and the two then drift apart.

It defines the terms used in `gamedata/`, `bridge/`, `apworld/` and `plugin/`.
Archipelago and Mann vs Machine share several words and mean different things by
them, and that file settles which meaning applies where.
